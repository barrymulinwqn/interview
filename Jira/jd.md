
### 岗位职责

负责 GitLab Self-Managed (Enterprise) 实例的日常运维、版本升级与补丁管理。  
维护 GitLab CI/CD Runner 集群的部署、扩缩容与性能调优。  
管理 GitLab 用户权限、Group/Project 配置及 SSO 集成。  
维护 GitLab 项目模板、CI/CD Pipeline 模板与 Group 级别策略。  
处理 ServiceNow 中与 GitLab 相关的用户工单。

### 任职要求

3 年以上 GitLab Self-Managed 管理经验，熟悉 Omnibus 及 Helm Chart 部署方式。  
精通 Git 工作流、CI/CD Pipeline 配置（.gitlab-ci.yml）及 Runner 管理。  
熟悉GitLab Geo、高可用架构及备份恢复机制。  
具备PostgreSQL 数据库运维能力。  
了解GitLab API 及自动化脚本开发。
